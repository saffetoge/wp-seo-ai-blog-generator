WordPress eklentisi ile ürün adına göre SEO uyumlu blog yazıları otomatik olarak oluşturun.

== Description ==

**WP Product Blog Generator**, ürün adlarından otomatik olarak SEO uyumlu blog yazıları oluşturan güçlü bir WordPress eklentisidir. Tek tıkla profesyonel, teknik özellikler içeren ve arama motoru optimizasyonuna uygun blog içerikleri üretin.

= Özellikler =

* **Otomatik İçerik Üretimi**: Ürün adı girdiğinizde otomatik olarak blog yazısı oluşturur
* **SEO Uyumlu**: Google ve diğer arama motorları için optimize edilmiş içerik
* **Teknik Özellikler**: Ürünle ilgili detaylı teknik bilgiler ekler
* **Schema.org Mikrodata**: Arama motorları için yapılandırılmış veri desteği
* **OpenGraph Etiketleri**: Sosyal medya paylaşımları için optimize edilmiş
* **HTML5 Semantik Etiketler**: Modern web standartlarına uygun
* **Responsive Tasarım**: Tüm cihazlarda mükemmel görünüm
* **WordPress Entegrasyonu**: WordPress standartlarına tam uyumluluk
* **Çoklu Dil Desteği**: İnternasyonalizasyon hazır
* **Güvenlik**: WordPress güvenlik standartlarına uygun

= Nasıl Kullanılır =

1. Eklentiyi aktifleştirin
2. WordPress admin panelinde "Blog Generator" menüsüne gidin
3. Ürün adını girin
4. "Blog Yazısı Oluştur" butonuna tıklayın
5. Oluşturulan içeriği kopyalayın veya doğrudan yazı olarak kaydedin

= Kimler İçin Uygun =

* E-ticaret site sahipleri
* Ürün inceleme blogları
* Affiliate pazarlama yapanlar
* İçerik üreticileri
* SEO uzmanları
* Dijital pazarlama ajansları

== Installation ==

= Otomatik Kurulum =

1. WordPress admin panelinde 'Eklentiler > Yeni Ekle' sayfasına gidin
2. Arama kutusuna 'WP Product Blog Generator' yazın
3. Eklentiyi bulun ve 'Şimdi Yükle' butonuna tıklayın
4. Kurulum tamamlandıktan sonra 'Etkinleştir' butonuna tıklayın

= Manuel Kurulum =

1. Eklenti dosyalarını indirin
2. Dosyaları `/wp-content/plugins/wp-product-blog-generator/` klasörüne yükleyin
3. WordPress admin panelinde 'Eklentiler' sayfasına gidin
4. 'WP Product Blog Generator' eklentisini etkinleştirin

= Kurulum Sonrası =

1. WordPress admin panelinde 'Blog Generator' menüsüne gidin
2. İlk ürün adınızı girin ve test edin
